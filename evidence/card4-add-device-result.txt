# 새 기기 추가(일회용 코드) 확인 결과 (가상 인증기 사용)
# 실행 시각: 2026-10-17T13:18:23.191Z

로그인한 노트북 화면에 일회용 코드가 나온다: ****-****  (실제 값은 가림)
통과  로그인한 기기가 일회용 코드를 만든다
통과  로그인하지 않으면 코드를 만들 수 없다(401) — status 401

## 새 휴대폰(로그아웃 상태)에서
코드 없이 등록 시작: 401 {"error":"unauthorized","message":"패스키를 더하려면 로그인하거나, 로그인한 기기에서 만든 일회용 코드가 필요합니다."}
통과  코드 없이는 새 기기에서 패스키를 더할 수 없다(401)
틀린 코드를 화면에 입력: 패스키를 더하려면 로그인하거나, 로그인한 기기에서 만든 일회용 코드가 필요합니다.
통과  틀린 코드는 거절되고 화면에 안내가 나온다
맞는 코드로 등록: 서버에 저장된 패스키 노트북, 내 휴대폰
통과  맞는 코드로 새 기기에 패스키가 추가된다(2개)
통과  추가한 기기는 바로 들어가진다

같은 코드를 다시 사용: 401 {"error":"unauthorized","message":"패스키를 더하려면 로그인하거나, 로그인한 기기에서 만든 일회용 코드가 필요합니다."}
통과  한 번 쓴 코드는 다시 통하지 않는다(401)
통과  코드를 계속 틀리면 잠시 막힌다(429) — status 429
통과  서버 기록에 코드 값이 남지 않는다
통과  이 결과 파일에도 코드 값이 없다

전부 통과 (10건)
